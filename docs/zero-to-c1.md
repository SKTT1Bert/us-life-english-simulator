# 零基础到 C1：学习路线、能力边界与记录

2026-10-22 新增六阶段学习路线：Pre-A1 零基础桥梁、A1、A2、B1、B2、C1。每阶段 8 课，共 48 课；每课 4 道理解题，共 192 题。六套阶段测评另有 48 道新题，共 240 道客观题。每课和每套测评均提供写作及口头任务、参考回应和三项具体自评标准。既有词根词缀与自然拼读各 48 课保留，按稳定 ID 链接到路线，合计 144 节可访问课程；两门专项另有共 72 道阶段测评题。

这是参考 CEFR 描述编排的课程与练习系统。课程数量不等于学习时数、词汇覆盖或已经达到某一级别。它支持从基础走向学术英语的练习路线，但不声称包含全部 C1 所需输入，也不是经过标准化验证的等级考试、录音评测或教师认证。研究生课程、学校和专业的语言需求不同；专业阅读与真实交流仍需持续练习。

## 阶段内容

| 阶段 | 核心任务 | 课程、练习与检查 |
| --- | --- | --- |
| Pre-A1 | 字母与读音、拼写个人信息、数字时间、简短请求 | 中文支架、短句材料、文字与声音联系、基础输出 |
| A1 | 自我介绍、日常安排、地点、购物、行动和邀请 | 常用句式、生活阅读与对话、简单信息交流 |
| A2 | 讲述经历、描述背景、比较、计划、建议与问题解决 | 多句连接、短消息、简短说明和学习总结 |
| B1 | 连贯叙述、表达理由、理解结构、澄清与合作 | 较长材料的主旨及细节、成段表达与迁移 |
| B2 | 理解论点、比较证据、解释图表、限定结论与讨论 | 复杂语言、反方观点、阅读听力综合、组织论证 |
| C1 | 学术词族与重音、讲座推理、证据强度、改写综合、研究限制与研讨交流 | 持续阅读与听力材料、来源比较、谨慎表达、学术写作及口头回应 |

## 四步学习闭环

1. **课程**：目标、中文讲解、词汇用法、原创阅读与听力。听力优先独立听，再展开文本核对；设备合成语音不等同于真人讲座。
2. **练习**：四题逐题反馈，已答题锁定，错题可重练；随后完成一项写作和一项口头任务。口头任务要求实际说出，再输入口述稿或反思。本页不录音、不上传音频，也不自动评判流利度。
3. **复习**：四题当前都答对且两项输出非空、三项自评都勾选，才进入次日复习。到期时先提交自己的回忆，再看要点，自评需要重学、部分想起或独立完成。
4. **测评**：每阶段使用新阅读与听力材料，8 道客观题和两项输出一次提交后显示反馈；未达成的输出自评项可以不勾选。客观题、输出自评、听力文本辅助分别记录，不自动宣布达到 CEFR 等级。

各阶段可直接进入，测评也可在学课前用于发现薄弱项。选择阶段只记录位置，不生成学习证据。首页显示路线的待复习课程和继续入口。四个左侧主导航保持不变。

## 复习与测评语义

- 首次完成后 1 天复习；需要重学加 1 天，部分想起加 3 天，独立完成依次加 7、14、30 天，最长 30 天。此为明确可检查的启发式规则，未声称经过学习者试验优化。
- 只能评价已到期课程；重复点击、未到期复习和错题重练不会刷复习次数。仅保留最新课程答案、输出、复习次数和日期，不保留完整课内作答历史或临时回忆文本。
- 输出内容改动后，界面清除旧自评；未完成的课程停止排期，重新完成后从次日恢复。重新保存已完整的草稿不会延后原有复习时间。
- 每阶段只保留最近 10 次测评；历史可以回看输出和自评。客观题分数从所选答案计算，导入不接受外部提供的总分。
- 阶段测评是固定练习材料。重复测评会受到熟悉题目的影响；它不是独立题库测出的标准化分数。
- 展开听力文本会标记使用辅助，本次提交前不能取消已发生的辅助记录。提交后查阅文本属于学习反馈，不反改原测评。

## 草稿、保存和兼容

课程输出输入后延迟约 450ms 自动保存。切换课程、离开路线和导出前会刷新等待保存的草稿；写入失败保留原存储，并把草稿暂留在内存供重试。关闭页面前若仍有失败草稿或未提交测评，会请求浏览器离开提醒。测评提交前的输入只在当前页面暂存；提交后才随学习进度永久保存。浏览器可能限制离开提醒，因此长文本仍应及时提交或另存备份。

导入和清空使用既有确认、预览和操作前备份；成功替换后立即取消旧定时器、语音和未提交的本页草稿，避免旧输入回写。课程文本最多各 8000 字符。所有用户文本按纯文本渲染。

新增可选 schema-v3 字段 `pathwayProgress`，内部版本为 1。缺少该字段的旧文件得到空路线进度。导出目前有 20 个顶层字段（包括 `app`、`exportedAt`），包含写作与口述文本，请按个人学习资料保管。没有新增服务器存储或账号同步。旧 v3 程序可能丢弃新增字段；回退前保留完整导出。

```json
{
  "version": 1,
  "levelId": "pre-a1",
  "lessonId": null,
  "lessons": {},
  "assessments": {}
}
```

课节记录包含 `answers`、`writing`、`speaking`、`checks`、`dueAt`、`reviews`、`lastReviewAt`、`updatedAt`。测评记录包含 `answers`、`writing`、`speaking`、`checks`、`transcriptUsed`、`submittedAt`。数组和选项顺序属于版本身份；未来改题、改选项或改评分含义时必须迁移或升级路线记录版本。导入校验阶段、课节、选项、完整字段、长度、真实 ISO 时间、时间顺序及完成与排期的关系。

## 验证

`tests/pathway-progress.test.js` 检查不可变状态、旧文件、作答与输出分离、自动保存、排期边界、复习与历史上限；`tests/pathway-content.test.js` 检查六阶段覆盖、唯一题目、有效基础课链接及高阶材料深度；`tests/pathway-browser.cjs` 使用实际 HTTP 页面验证课程、写作、测评、复习、存储失败、导入导出、清空竞态、语音生命周期、主题与窄屏。

自动测试不判断一篇开放写作是否真正达到 C1，也不验证学习效果。更可靠的下一步能力检验是在未见过的材料上完成理解、讨论与写作，并取得教师或合格测评者反馈。
