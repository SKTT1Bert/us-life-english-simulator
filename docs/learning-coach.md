# 今日学习计划与学习报告

学习计划把已有表达、综合路线、词根词缀、自然拼读和逐句精听连接起来，不另建一份课程完成记录。

## 计划如何产生

- 选择 5、10 或 20 分钟的学习预算、当前想学的阶段和日常／学术／工作用途，点击“更新计划”保存。
- 优先安排已到计划时间的表达和课程复习，其次是当前未订正的随堂题，再接续已有课程或选择相同阶段、与用途相关的小步骤。
- 课程有序号、内容和已有进度。开始一课不会记为完成；三分钟步骤只是读一个知识点、试一道题、练一句或准备一段输出，不能代表整节课程所需时间。
- 每次刷新建议都从当前已保存的记录计算，不改动原来的每日表达列表。做完后，建议可以随最新证据变化。
- 学术／工作用途只影响当前所选阶段中的主题顺序，不自动跳级。所选阶段也不是已测得的英语水平；起点诊断只提供学习建议。

`LearningCoach.buildPlan(progress, catalogs, now)` 是无副作用纯函数。`catalogs` 包含 `pathway`、`foundation` 和 `expressions`。

## 报告的统计含义

- “完成课内学习要求”要求题目全对、写作和口述要点非空、三项自评全部完成，与现有综合和基础课程引擎一致。它不是教师批改结果，也不是已达到某个 CEFR 等级。
- 当前正确数按保存的随堂答案核对，未作答题不算错题。完成后的旧测评仍保留历史尝试，不替换成当前课内成绩。
- 最近七天按 UTC 换日，以已保存的表达练习、句子练习、测评、诊断提交和每节课的最近更新时间显示有记录的日期。原程序没有保存完整课程修改历史，因此报告不声称展示全部学习活动或学习时长。
- 精听逐句取最新尝试。只有确实发起过播放、未查看原文且文本完全匹配时，才进入相应听写统计；多写单词也不能算完全正确。跟读“独立”单独作为用户自评显示，不能当作自动发音评分。
- 表达回忆的“独立说出”来自原有主动回忆自评；至少隔 24 小时的成功直接读取原引擎保存的 `delayed` 字段，不从“已学习”或选择题正确猜测。

## 集成与保留

`LearningCoach.mount({today, report, getProgress, getCatalogs, commit, navigate})` 挂载两个容器。`getProgress` 返回完整进度快照，`getCatalogs` 返回当前课程与表达目录。保存偏好使用 `commit({type:'preferences', patch})`，只提交实际修改的字段，成功才更新界面提示。刷新不会丢掉尚未保存的偏好选择。“放弃设置修改”恢复已保存值；`hasPendingWork` 让同步在草稿存在时推迟应用远端更新，`resetSession` 在确认导入或清空后清除草稿。

本模块只读取记录并产生建议。持久化、加密同步、导入导出和存储失败处理由共用的学习工作区进度引擎负责。所有用户文本使用 DOM 文本节点呈现。

验证入口：`node --test tests/learning-coach.test.js` 和 `node tests/learning-studio-browser.cjs`。浏览器验收使用独立测试记录，覆盖偏好保存、行动按钮跳转、移动布局、三种主题、导入导出，以及有未保存设置时推迟同步。声音与云端接口为显式测试替身，不能代替真实音频和线上接口验收。
