# 加密同步版本验收 · 2026-10-23

本版为既有 GitHub Pages 学习页面添加自愿开启的配对同步，并在首页集中显示三类课程尚未订正的题目。具体用法、同步范围与限制见 [多设备同步说明](private-sync.md)。

## 发布前检查

- 148 项单元测试通过，覆盖既有课程/复习引擎，以及加密、合并、离线重试、并发版本检查、断开后重连、损坏设置和中断保存恢复。
- 原有六套浏览器检查覆盖课程、练习、复习、测评、个人表达、旧版迁移、导入导出和移动布局。
- 新增 5 项浏览器单写入保护检查和 10 项双浏览器模拟接口检查。
- 真实 HTTPS 同步服务通过创建、读取解密、更新、并发冲突、错误凭据、来源限制和预检检查。
- 本地前端以生产网页来源访问真实服务，9 项双浏览器检查通过。该检查没有拦截同步接口，使用虚构记录；前端文件仍来自本地，不代表该时刻 GitHub Pages 已更新。
- 后端 16 项实际 SQLite 事务测试通过，覆盖分块密文、并发写入、事务失败回滚和持久限流。

同步服务的首次发布源提交为 `a96b81ab4c1994685daa853307d16a46289088bd`，Sites 版本 1，生产地址为 <https://daily-english-private-sync.feyloom36.chatgpt.site>。服务入口公开和加密数据目的地已经项目所有者明确同意；不存在公开的学习记录列表。

## 发布后的验证入口

`SYNC_PRODUCTION=1 node tests/sync-browser.cjs` 使用已部署前端和真实接口，单独创建一个虚构测试空间。默认不设置此变量的 CI 只使用模拟接口，不会持续向生产空间写入测试数据。真实验证需要注意创建/写入频率限制。

手机检查使用独立浏览器环境，覆盖 390×844 竖屏和 844×390 横屏；未声称完成 Android/iOS 真机测试。配对后的同步只在页面打开并联网时运行，未提交测评仍属于当前页面。

## 回退

前端可回退至本版之前的提交。保留原主进度键及 `daily-english-sync-*` 项，回退不应清理浏览器记录或云端存储。出现同步服务故障时继续使用本地课程，导出当前记录备份；修复后使用原配对码继续同步。
