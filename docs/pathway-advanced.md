# B1 到 C1：进阶与学术阶段

核对日期：2026-10-22。能力阶段对照 CEFR 官方描述，课程分级为编辑判断，不是经过验证的等级认证。所有阅读、听力、题目和参考回应为项目原创。每阶段 8 课、32 道课内题、8 道独立测评题及写作和口头任务；详细运行语义见 [学习路线](zero-to-c1.md)。

## B1 · 把英语用于独立学习与生活

从连贯叙述、说明理由和解决沟通问题，走向短文概括与小型项目。阅读和听力材料分开，先听后看文本。

| 课节 | 训练重点 |
| --- | --- |
| 讲清经历：背景、变化与结果 | 区分故事背景和先后发生的事件；用具体事件支持感受和反思 |
| 读懂条件，说明操作步骤 | 从说明中区分必做事项与条件事项；在沟通中确认时间和责任 |
| 比较选择，不只说更好 | 用共同标准比较两个方案；理解让步后仍成立的理由 |
| 解释陌生事物，修复误解 | 用关系从句和例子解释陌生词；通过复述确认双方理解一致 |
| 提出观点，也承认范围 | 区分观点、例子与一般结论；写出有理由和限定的意见段 |
| 用词族读懂通知与短文 | 结合句法位置判断词族成员的用途；不把熟悉词缀当成整词含义的保证 |
| 听重点与纠正，不追逐每个音 | 识别 but、actually 等转折与纠正信号；用语块和对比重音传递明确含义 |
| 完成一个有反馈的小项目 | 从多条反馈中归纳重点并说明限制；写出问题、行动、观察和下一步 |

阶段测评：写 160–200 词给新志愿者的说明与建议，整合两份材料；包含两项操作、一个尚不确定的结果和收集证据的方法。 用 2 分钟向未参加的人解释活动如何运作，再回答：“为什么不直接说新标牌提高了出席率？”请写下口述提纲或实录。

## B2 · 进入大学学习：分析、讨论与论证

处理较长说明与论证，比较证据，解释研究限制，并为不同读者调整表达。任务从理解细节推进到判断推论。

| 课节 | 训练重点 |
| --- | --- |
| 评价来源：谁说的，凭什么 | 区分来源权威与具体主张的证据；说明一份材料能回答和不能回答的问题 |
| 相关、原因与替代解释 | 识别观察性比较无法自动支持因果的原因；用合适限定词表达结果与替代解释 |
| 解释数字、分母与比较 | 区分比例、人数、百分点与相对变化；判断汇总数字是否掩盖组别或时间差异 |
| 论证与反驳：回应最强顾虑 | 识别主张、理由、反对意见和回应；用条件性建议避免虚假的二选一 |
| 改写并综合两种观点 | 用自己的结构表达原意并保留限制；围绕共同问题组织多个来源，而非逐篇罗列 |
| 学术词族、名词化与清晰表达 | 拆解抽象名词并恢复动作与执行者；在专业表达与读者可理解性之间调整 |
| 跟随讲座结构，提出有用问题 | 识别讲者的主张、例子、限制与转向；提出能推进讨论的具体澄清或应用问题 |
| 写出可评估的项目建议 | 把问题、方案与评估指标对应起来；区分可行性、体验与效果的证据 |

阶段测评：写 280–320 词给院系的建议，综合两份新材料；提出有条件的方案、证据需求和一项合理反对意见，解释现有试行不能支持什么结论。 做 3 分钟简报，说明“可见”与“可及”的区别，并回应：“借用次数多，为什么还不能证明成功？”保存口述提纲或实录。

## C1 · 学术理解、论证与研究交流

在较长材料中追踪论证、判断证据与限制，综合不同来源，并以清楚而审慎的语言参与研究讨论。案例中的机构、研究和数据均为原创虚构教学材料。

| 课节 | 训练重点 |
| --- | --- |
| 词根词缀进阶：把抽象名词还原成论证 | 在语境中区分观察、解释、推论等词族功能；将密集名词结构还原为谁做了什么，不改变限定条件 |
| 拼读进阶：词族重音、意群和讲座转折 | 区分词内重音与句子焦点，不按构词边界机械停顿；通过路标和修正语追踪讲座中观点的变化 |
| 批判阅读：相关、机制与因果 | 识别选择偏差与替代解释如何影响因果结论；提出能区分解释的进一步证据，而非笼统要求更多研究 |
| 谨慎而有立场：校准结论强度 | 把不确定性定位到原因、范围或测量，而非机械堆叠 may；区分没有发现效应与已经证明没有效应 |
| 跨来源综合：围绕问题组织证据 | 比较来源的对象、指标和范围，解释表面冲突；围绕问题形成综合判断，不把来源摘要简单串联 |
| 准确改写：保留意义、范围与来源 | 改变表达组织而不扭曲原文限定和对象；区分引用来源、作者主张与自己的推论 |
| 研究方法与局限：从标签走向解释 | 解释操作化与测量误差如何影响结论；针对一个局限说明影响方向或不确定性，并提出可行改进 |
| 研究生研讨：提出方案、回应质疑与修订 | 在讨论中准确复述质疑，再有条件地回应；综合证据、可行性和公平性提出可修订的方案 |

阶段测评：写 450–550 词的评估备忘录，向研究生院提出有条件的建议。综合阅读和讲座，分析至少两项证据限制，区分观察与推论，设计可行的评价与修订条件。用“虚构报告／委员会回应”标注材料，不编造文献。 做 4 分钟简报，然后回答：“登记数增加为什么还不够？”及“如果部门想要不同方案，你如何决定？”保存实际口述稿或包含回应与修订的反思记录。

## 内容边界与核验

词根词缀用于形成词义假设；语境和词典决定具体用法。词族重音需要逐词核对，合成语音不是音素课程或发音评分。学术案例和命名来源均为虚构教学材料，不能作为真实研究、作者或数据引用。课程中的模型回应可能是论证框架或片段，不应把照抄参考当作独立输出。

每课理解题区分阅读和听力，并提供答案依据。测评使用不同材料，输出量规聚焦任务、意义和表达。程序校验结构、唯一题目、链接和文本长度；人工核对材料与答案的关系、语言规则、证据限定和课程递进。未进行外部教师等级标定或学习者效果研究。
