# 学习工作台：功能与发布检查

2026-10-25。本轮将已有课程接入今日计划、起点诊断、逐句精听和学习报告。原有四个主导航、144 节课程、表达复习与加密配对继续使用；没有新增收费接口、录音上传或自动发音评分。

## 可以怎样使用

- **今日计划**：选择 5／10／20 分钟、学习阶段和用途。先处理已安排的复习与未订正题，再安排一小段新课、基础练习或精听。时间是预算，不代表整节课程完成时间。参见[计划与报告的统计含义](learning-coach.md)。
- **起点诊断**：24 道原创文字题覆盖六个阶段，支持跳过、返回修改、明确提交、查看解析和历史尝试。推荐从最早证据不足的一组开始试学，不会自动跳课、清空复习或标记完成。
- **精听与跟读**：现有 48 篇综合课程听力材料支持逐句播放、调速、听写核对、原文辅助、跟读自评和薄弱句重练。保存结果与辅助标记，不保存听写输入或声音。无英文语音时给出文字练习降级提示。
- **学习报告**：按 UTC 显示最近七天的已保存证据、当前随堂作答与课程进展、待复习内容及听写／跟读情况。课程只有最近保存时间，因此活动图不表示完整活动日志或学习时长。

## 数据、兼容与恢复

仍使用原主存储键 `daily-english-lab-state-v1` 和导出 schema v3。新增可选 `learningStudio` 字段（内部版本 1），包含偏好、已提交的诊断答案和精听结果元数据。旧备份缺少该字段时补为空值；原有答案、写作、口述要点、复习、测评、收藏和个人表达不被重算。字段定义见[运行时数据字典](../metadata/data_dictionary.csv)。

这些已保存记录随正常导出／导入和已有加密配对同步流转。正常导出仍是可读的 JSON 文件，不等于加密档案。导入前预览，并保留操作前备份；格式错误、未知材料、容量超限或保存失败时保留原记录，不显示为成功。达到 100 次诊断或 10,000 次精听记录上限会停止新增并提示备份，不自动删旧记录。

未提交诊断、精听输入和未保存计划设置属于页面草稿；同步会推迟应用可能覆盖它们的更新。明确保存、放弃草稿，或确认导入／清空后才恢复对应流程。偏好只提交实际改动字段；跨设备同步按字段合并，诊断和精听尝试按唯一编号保留。

**升级时请刷新每台已配对设备。** 旧缓存页面不认识新增同步条目，会停止应用不兼容的云端数据并保留本机记录。此时不要重新建空间、清空浏览器或用旧客户端导入新备份；先导出本机记录，再刷新至新版，继续使用原配对码。服务异常时仍可本地学习，联网打开页面后重试。完整同步与备份限制见[多设备同步说明](private-sync.md)。

回退代码前先导出新版完整进度，并保留所有主进度与 `daily-english-sync-*` 存储项。旧程序不理解新增字段；代码回退不能视为数据向下兼容，也不应借此清理记录。

## 能力边界

诊断题未经过真实学习者难度校准，且不测试听力、口语与写作，**不是 CEFR 认证或正式分级考试**。课程标签代表目标练习阶段，不能直接证明已达到该水平。学习报告将标准答案核对与用户自评分开，不把完成按钮当作熟练度证据。

朗读使用设备 SpeechSynthesis 英文语音，**不是制作好的真人音频**。跟读结果来自用户自评，不录音、不调用发音评分服务。语音是否可用、音色与质量取决于浏览器及设备，必须在实际设备上另行核对。

这是一轮可验证的产品能力升级，不以功能数量宣称已达到行业领先或学习效果优于其他平台。后续内容审校、真人音频制作、评测校准与真实使用研究见[官方平台对照](platform-benchmark-2026-10-25.md)。
