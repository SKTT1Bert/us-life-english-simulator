# 英语基础：系统课程与学习记录

2026-10-22 版本将原来的词根词缀 6 课、自然拼读 6 课扩展为各 24 课。每课包含目标、分步讲解、至少 3 个例词、注意事项、3 道带解析的练习和参考链接，共 48 课、144 题。两门课程保留原 12 个课节 ID。

完整指一个有起点、进阶和综合应用的**核心基础课程**，不是英语全部词根、拼写和口音的穷尽清单，也不是获认证的教材或 CEFR 测评。词源与现代构词关系会区分；拼读规律连同例外学习。覆盖与来源见 [词根词缀](word-parts-curriculum.md) 和 [自然拼读](phonics-curriculum.md)。讲解、翻译、例词说明和题目由项目编写，来源用于核对规则与用法。

## 学习流程

- 目录默认收起，可按阶段筛选、搜索标题和例词，直接访问任意课节。
- “继续学习”返回上次未完成课；上次课已完成时进入第一节未完成课。
- 逐题作答后显示解析。已答题不能重复提交；“重练错题”只清除当前错题，“重新练本课”清除本课当前答案。
- 全部 3 题当前答案正确才显示“练习完成”。它不代表首次正确率、延迟保持、熟练度或口语能力；记录仅保留最新答案。
- 设备英语语音优先选择 en-US，播放完整单词或有语境的短语、句子，不是逐音素录音。没有录音上传、识别或自动评分；不支持朗读时提示使用标注或词典来源。

## 数据、导出与回退

课程记录纳入现有 `daily-english-lab-state-v1` 主存储和 JSON 导出，以可选 `foundationProgress` 扩展 schema v3。加入 [零基础到 C1 路线](zero-to-c1.md) 后，导出共 20 个顶层字段（含 `app` 和 `exportedAt`）。旧 v1/v2/v3 文件缺少该字段时得到空课程记录，不生成学习证据。

```json
{
  "version": 1,
  "courses": {
    "word-parts": {
      "lessonId": "word-parts-basics",
      "records": {
        "word-parts-basics": {
          "answers": [0, null, null],
          "updatedAt": "2026-10-22T00:00:00.000Z"
        }
      }
    },
    "phonics": { "lessonId": null, "records": {} }
  }
}
```

`answers` 按课内顺序存储所选选项的零起始索引；`null` 表示未答。课节 ID、题目和选项顺序属于记录身份，未来改变题意或顺序时必须迁移或增加课程记录版本。完成数从答案计算；恢复校验版本、课节、数组长度、选项范围和时间字段，无效导入会被拒绝。

先持久化再替换内存，写入失败不改变原记录，并显示失败；课节仍可阅读。导入和清空保留既有确认和操作前备份，立即刷新课程 UI。课程与表达 Recall 的成绩和调度独立。

旧 schema-v3 程序可能忽略并在保存时丢弃新增字段，回退前请保留完整导出。旧 v1/v2 程序仍拒绝 v3。课程没有跨设备同步。

```sh
node --test tests/foundations.test.js
node tests/foundations-browser.cjs
```

检查覆盖课程结构、旧 ID、来源链接、空记录迁移、重练、记录边界、导航、刷新、导出回导、清空、存储失败、语音不可用、主题和窄屏。实际设备语音音质、专业教师课程审定和学习效果不由自动测试验证。
