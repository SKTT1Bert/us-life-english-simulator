# 词根词缀与自然拼读：Pre-A1 到 C1 专项课程

两门原课程现各有 48 课，按 Pre-A1、A1、A2、B1、B2、C1 分为六阶段，每阶段 8 课。每课有目标、至少三段讲解、三个例词或语境示例、三道带解析的随堂题、书面与口头任务、三项自评、独立主动回忆卡及参考链接。每门另有六套阶段测评，每套三道阅读/语言分析题、三道听力理解题及两项输出任务。两门合计 **96 课、288 道随堂题、72 道阶段测评题**。

与另有 48 课、240 题的[综合学习路线](zero-to-c1.md)双向衔接，总计 144 课、600 道专项及路线客观题。这不包括原应用的表达识别、场景与市场英语题目。计数表示项目内容规模，不等于完成 C1 所需词汇量或教学时数。

课程细目与来源见[词根词缀](word-parts-curriculum.md)及[自然拼读](phonics-curriculum.md)。高阶词根课程关注学术词族、名词化、搭配、概念边界和谨慎表达；高阶拼读课程从解码延伸到词族重音、意群、数字信息、学术听力和研讨表达。阶段是依据能力描述安排的编辑分级，专项课程不能单独证明综合 C1 能力。

## 学习流程

1. 选阶段，在收起的目录中搜索、筛选或直接选课。所有课开放。
2. 看讲解、例词和标注，逐题作答并查看解析。“重练错题”保留正确答案，“重新练本课”清除当前答案。
3. 完成书面与口头任务。口头栏保存实际练习后的口述稿、标注或反思，不保存录音。输入 450 ms 后自动保存，也可手动保存；改动文字会清除自评勾选。
4. 三题全对、两项输出非空、三项自评勾选后，安排次日主动复习。先写回忆再揭晓要点，按“需要重学 / 有些吃力 / 顺利回忆”安排 1 / 3 / 7 天，后续顺利回忆为 14 / 30 天。到期前不能重复推迟计划。
5. 用每阶段独立材料测评，提交全部理解题及两项输出，自评可保留未勾选。客观分数和输出自评分别展示，最多保留每阶段最近十次提交。再次做相同材料属于复习，不是独立等级认定。
6. 点击“衔接本阶段综合路线”练听说读写；综合路线也能直接返回同阶段的词根与拼读课。专项与综合练习分别记录，跳转不自动授予完成状态。

全课程进度条保留“随堂题全对”含义；阶段卡另外展示输出自评完成、到期复习及测评次数。“继续学习”优先返回上次尚未完成随堂题与输出的课程。

## 数据与兼容

主存储仍为 `daily-english-lab-state-v1`，主导出仍为 schema v3，20 个顶层字段。`foundationProgress` 内部升级为版本 2：

```js
{version:2,courses:{
  'word-parts':{levelId:'pre-a1',lessonId:null,records:{},assessments:{}},
  phonics:{levelId:'pre-a1',lessonId:null,records:{},assessments:{}}
}}
```

每个 `records[lessonId]` 保存 `answers`（三项 null 或有效选项索引）、`writing`、`speaking`、`checks`（三个布尔值）、`dueAt`、`reviews`、`lastReviewAt`、`updatedAt`。每段输出最多 8000 字符。每个 `assessments[levelId]` 保存最多十项 `{answers,writing,speaking,checks,transcriptUsed,submittedAt}`；测评答案是六个选项索引，不允许 null。当前分数从固定答案键计算，不接收导入文件自报的分数。课节/测评题意、选项次序及答案含义是版本化记录身份；后续改变时须迁移记录或升级内部版本，不能静默重解释旧答案。

保留之前 48 个课节的所有 ID、题目内容、选项次序和答案键，测试用固定快照核验。旧版 `foundationProgress.version:1` 会保留答题证据和最后位置，迁移到对应阶段；新增输出为空、自评为 false、复习未安排，不伪造学习成果。缺少该可选字段的旧导出得到空进度。

版本、字段、课节/阶段关系、答案长度、选项范围、文本长度、时间顺序和复习计划由共享纯函数引擎校验。无效导入不替换原数据。先写本地存储再更新活动状态；失败会保留原记录，未保存草稿暂存在页面中。导出前刷新待保存课程草稿，仍失败会提示另外复制文本。导入和清空成功后取消旧草稿计时器，避免旧输入重新写回。

课内输出草稿随主进度保存；阶段测评提交前草稿仅暂存在页面，刷新前会提示，提交后才进入导出；主动回忆输入只用于当次核对，不保存。导入/清空维持原有确认与操作前备份。数据没有跨设备同步；回退到只支持课程版本 1 的旧应用前，请保留完整导出。

## 语音、评估边界与验证

设备合成语音用于完整词语、句子及听力文本练习，不保证精确示范指定重音、停顿或语调。涉及对比重音的题目使用显式书面标注，不假设合成语音实现了声学对比。缺少语音支持时可以用文本辅助；测评展开听力文本会记录辅助标记。不同合法口音均可具有清晰度，目标不是模仿唯一口音。

没有自动录音分析、发音/流利度/写作评分，输出评分是学习者自评。课程与固定自测不能替代真人材料、教师反馈和正式能力测评。来源用于核对规则与教学安排，原创材料不是外部机构认证试题。
