# 导航与布局

主导航保留四个入口，具体内容放在页面上方的二级导航中：

| 主入口 | 默认页面 | 二级页面 |
| --- | --- | --- |
| 今日 | 今日学习 | 无 |
| 学习 | 表达库 | 表达库、英语基础、场景模拟、市场英语 |
| 练习 | 练习与复习 | 无 |
| 我的 | 学习进度 | 学习进度、收藏 |

同一次打开网页期间，重新进入“学习”或“我的”会回到该组最后访问的页面。刷新网页后回到今日学习；导航不新增本地存储数据。原有视图 ID 保持不变，页面内的“练习回忆”等跳转仍通过 `setView()` 同步主导航和二级导航。

桌面主导航宽度为 192px，减少左侧占用。手机显示为一行四个入口，隐藏说明和侧栏累计数字。场景模拟沿用宽屏布局，同时在上方保留四个主入口，避免进入场景后失去导航。手机首页的三个统计数字也保持一行，让复习内容更早出现。

导航使用原生按钮，支持 Tab、Enter 和 Space；方向键在当前导航内移动焦点，Home/End 移到首尾。当前入口使用 `aria-current`，隐藏的二级菜单不会进入键盘顺序。三种主题沿用现有颜色变量，尊重减少动态效果设置。

验证应覆盖：八个旧视图均可到达、组内最后访问页面、页面内跳转同步、方向键操作、手机无水平溢出，以及场景模式仍能离开。截图检查需要等待或关闭 CSS 过渡，避免把切换主题的中间帧当成最终颜色。
