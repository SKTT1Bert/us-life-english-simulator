# 多设备自动同步

在学习页面右上角打开“多设备同步”。第一台设备选择“创建我的同步空间”，保存配对码；另一台设备输入同一份配对码，选择“连接并合并记录”。每台设备只需连接一次，手机和电脑不用同时在线。

记录先保存到当前浏览器。页面打开并联网时，修改会自动上传；重新联网、回到页面或点击“立即同步”也会检查更新。关闭网页期间不会在后台同步。请等到显示“已同步”再清除浏览器数据。

## 数据与保留

- 同步范围：表达学习与收藏、个人表达、练习记录、复习安排、综合路线、词根词缀、自然拼读的已保存作答、写作与口述要点，以及已提交的测评。
- 尚未提交的测评答案属于当前页面的临时内容。完成并提交后才加入同步；收到云端更新时，不会打断或清空正在进行的测评。
- 首次配对合并已有记录，不用空记录替换另一台设备。历史累计次数按较大值作为起点，避免同一份旧备份被重复累加；配对后使用设备增量记录新的次数。
- 同一课被离线修改成不同版本时，会保留完整副本。同步面板可以查看或下载。页面通常展示一个确定的版本，保留的其他版本不是新的评分结果。
- 收藏取消和个人表达删除会传播到已配对设备。删除个人表达会从学习与复习中移除该表达，但已保留的同步副本和历史记录不会一并删除。
- 断开同步会保留本机记录和云端记录，不影响其他设备。清空本机或导入替换备份前，先断开此设备。
- 原有主存储键和 schema v3 格式继续使用；首次连接前另存本机备份，接收云端记录时使用恢复日志，防止中途关闭或存储失败导致半份记录。
- 一个浏览器同时使用一个学习页面；第二页会等待第一页面关闭后载入最新记录，避免多个页面争相保存。
- 开启同步时，导出文件还包含完整同步封装，保存额外的历史和冲突副本。普通导入恢复当前学习记录；这些额外副本作为归档留在文件里，不会恢复配对关系或自动写回云端。普通文件上限为 5 MiB，含有效同步封装的备份上限为 12 MiB。

## 配对码与云端

服务地址为 `https://daily-english-private-sync.feyloom36.chatgpt.site`，前端继续托管在原 GitHub Pages 地址。此目的地和公开服务入口由项目所有者明确批准。服务入口可访问，不代表学习记录公开。

配对码由设备随机生成，具有 160 位随机量，不是容易猜到的短数字。设备通过 HKDF-SHA-256 分别派生同步空间标识、访问凭据和 AES-256-GCM 加密密钥。每次加密使用新的随机 IV，并将密文绑定到同步空间。服务仅接收空间标识、访问凭据及密文，数据库保存访问凭据的哈希、版本号和分块密文；不接收配对码或解密密钥。网络传输使用 HTTPS。

持有配对码的人能读取和修改记录。配对码会保存在已连接设备的浏览器存储中，因此也需要保护设备和浏览器账号。不要公开配对码，不要放在 GitHub issue、截图或共享文档里。丢失所有已配对设备和配对码后，服务不能恢复密钥；“导出进度”仍可保存独立备份。导出的学习文件本身包含明文内容，请妥善保管。

后端通过版本比较和数据库事务保护并发写入，冲突会重新读取并合并。拒绝错误凭据、无效格式和超限内容；限制创建和写入频率。前端最多保留约 6 MiB 的同步封装，后端密文上限为 8 MiB。达到容量或频率限制时保留本机记录并显示提示，不静默删减历史，也不会显示为已同步。

## 维护与回退

2026-10-25 表达工坊扩展：已保存的写作、口语转写、反馈、自评和新版阶段小测也加入原配对空间。原始音频不保存、不上传；逐事件记录支持并发合并，空的新设备或缺少新字段的旧快照不会删除新记录。两台设备都应刷新到新版后继续同步；正在录音、处理或有未保存的工坊内容时，会等待你保存后再应用远端记录。见 [表达工坊兼容说明](speaking-writing-release.md)。

客户端加密、合并、控制器、界面分别位于 `syncCrypto.js`、`syncMerge.js`、`syncController.js`、`syncUI.js`；`syncApp.js` 将其接到既有学习页面。后端作为独立 Sites 项目维护，使用 D1 和受版本控制的迁移。生产环境不得启用本地开发的创建请求豁免。

出现服务故障时，本地课程仍可使用，待网络恢复后重试。回退前端时保留原主进度和所有 `daily-english-sync-*` 存储项；不要用回退操作清空它们。需要重新连接时使用原配对码。合并算法依赖既有课程和题目标识；课程变更应维持兼容性。
