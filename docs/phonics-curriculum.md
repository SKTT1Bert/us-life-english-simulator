# 自然拼读：24 课核心基础路线

内容核对日期：2026-10-22。课程数据位于 `data/phonics.js`。

本路线面向需要中文支持的成人英语学习者，将原有 6 节入门课扩展为 24 节系统基础课。共四个阶段，每阶段六课，包含 72 道选择题和 104 个例词或有语境的词例。每课提供两个学习目标、三个讲解步骤、至少三个拆解例词、三个各有唯一答案的练习及解析，以及可追溯来源。中文讲解、题目、拆解和学习提示为本项目编写；词本身并非新造词，也不将本课程称为来源机构认证的课程。

“完整”指下列核心学习路线已经配齐讲解、例词、练习和阶段复习，并非覆盖全部英语单词、全部拼写对应或全部口音。认字与拼读还需结合词汇、理解和真实语境；仅完成选择题不能证明发音正确或达到某个英语等级。

## 标音、分块与音频约定

- 使用宽式、常见 General American 基准。`/r/` 表示英语 r 的教学宽式写法；不要求卷舌弹音。`/ɝ/` 与 `/ɚ/` 分别用于本路线的重读与非重读 r 色彩元音。
- 使用 `/i u ɛ/` 等写法；部分词典写 `/iː uː e/`。这类符号约定的差别不等于实际发音错误。长、短元音是传统拼读类别，不能只用持续时间解释。
- 保留 `/ɔ/` 与 `/ɑ/` 便于展示模式，同时明确一些美式口音合流。wh/w、是否保留元音后 r、tomato 等另作口音说明；不假定全国只有一种美式或英式读法。
- `/ɪz/`、`/ɪd/` 是词尾练习的统一宽式写法，实际语流及部分标音系统使用 `/əz/`、`/əd/`。示例省略闪音、送气、不完全爆破等细节，不冒充精密语音转写。
- `+` 和音节分块用于辅助学习，可能表示声音、拼写块或明确标注的构词块；不把它们混称为语素。stopped 明确写为 stop + ed（双写 p），没有虚构 “-ped” 后缀。教学分块不必与词典的语音边界完全一致。
- 朗读按钮调用设备 TTS，播放完整单词或标明的短语、句子。它不是纯音素示范，不录音、不自动打分，也不能验证学习者的发音。read/record 等同形异音例词使用语境文本减少歧义，但 TTS 仍可能选错读音，应查所列词典的词性、标音与真人录音。

## 来源与使用边界

来源用于核对教学概念、范围和特定读音，课程顺序与中文材料由本项目组织；没有复制来源的整套课件、录音、题库或例句。

1. [University of Florida Literacy Institute — Glossary](https://ufli.education.ufl.edu/resources/teaching-resources/glossary/)：核对 phoneme/grapheme、合音/拆音、digraph/blend、词块及规则/不规则词等术语。另参考其公开 [Foundations 概述](https://ufli.education.ufl.edu/foundations/) 和 [Toolbox](https://ufli.education.ufl.edu/foundations/toolbox/) 了解系统教学结构；本课程不复制其完整范围与教学程序。
2. [IES What Works Clearinghouse — Foundational Skills Practice Guide](https://ies.ed.gov/ncee/WWC/PracticeGuide/21)：参考从音素—字母联系到解码、词块与连贯文本的教学方向。该指南主要针对 K–3；本项目的成人中文自学版本没有因此获得独立效果验证。
3. [Reading Rockets — Six Syllable Types，Louisa Moats 与 Carol Tolman](https://www.readingrockets.org/topics/spelling-and-word-study/articles/six-syllable-types)：核对六类书面音节框架。本路线明确采用较窄的 consonant-le 类；UFLI 的 final-stable 分类范围更广，两者不强行等同。
4. Iowa State University 开放教材 *Teaching Pronunciation with Confidence*：[Vowels](https://iastate.pressbooks.pub/teachingpronunciation/chapter/chapter-3-vowels/)、[Consonants](https://iastate.pressbooks.pub/teachingpronunciation/chapter/4-consonants/)、[-ed and -s Endings](https://iastate.pressbooks.pub/teachingpronunciation/chapter/chapter-5-ed-and-s-endings/)、[Word Stress](https://iastate.pressbooks.pub/teachingpronunciation/chapter/6-word-stress/)：核对辅音/元音、词尾和重音的教学处理，特别区分增加辅音与增加音节。
5. [Cambridge Dictionary 发音索引](https://dictionary.cambridge.org/us/pronunciation/) 提供 US/UK 标音和真人词音的后续核对入口；[record 的词性与读音](https://dictionary.cambridge.org/us/pronunciation/english/record?a=british)、[war](https://dictionary.cambridge.org/us/dictionary/english/war)、[UK/US pronunciation 说明](https://dictionaryblog.cambridge.org/2025/10/29/you-say-to-may-to-and-i-say-to-mah-to-uk-us-pronunciation/) 支持本路线相应的具体对比。
6. [Collins English Dictionary — read](https://www.collinsdictionary.com/us/dictionary/english/read)：核对 read 现在式与过去式的不同读音。本路线统一为自身宽式 IPA 风格，不把不同词典的排版差异当成读音差异。

不会把来源中儿童识字教学的证据直接转成成人发音成效承诺，也不声称 24 课可替代听辨训练、教师反馈、实际交流或完整阅读课程。英语借词、专名、低频历史拼写、所有口音的细节及高级连读仍需要进一步学习。

## 数据兼容与维护

原有六个 ID `sounds-and-blending`、`short-vowels`、`digraphs-and-blends`、`silent-e`、`vowel-teams`、`syllables-stress-schwa` 以及各自原来的第一题保持不变。课程按新的学习顺序排列，持久化引用应使用 ID，不应依赖旧数组下标。

每课现在提供 `stage`、`goals`、`sources` 和三题 `quizzes`；`quiz` 与 `quizzes[0]` 指向同一题，兼容旧的单题读取。课程题目只记录规则识别；学习进度与真实发音能力应在界面和导出语义中保持区别。后续如改动答案或题意，需考虑已有记录的版本语义，不应默默把旧作答解释为新题成绩。
