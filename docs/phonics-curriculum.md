# 自然拼读与学术语音：Pre-A1 → C1 六阶段路线

核对日期：2026-10-22。课程：`data/phonics.js`；阶段测评：`data/phonicsStages.js`。

原来的 24 课现已扩展为 **48 课，六阶段各 8 课**，包含 176 个例词/短语/句例、144 道单课选择题和 36 道独立阶段题，共 180 道客观题。每课都有三个讲解步骤、学习目标、至少三个例子、三题练习及解析、独立书写/标注任务、口头演练记录、三项自查、回忆卡和同阶段主路线链接。每阶段另有原创阅读与听力材料、3 道阅读题、3 道听力题，以及输出任务、自查标准和参考模型。

这里的阶段是成人自学的课程组织和目标衔接，**不是 CEFR 官方规定的拼读词表，也不是仅靠发音专项就能取得 C1**。Pre-A1–A2 主要建立解码与词音基础；B1–C1 转向清楚连贯表达、学术听讲、研究汇报与互动修复。研究生学习还需要词汇、语法、长篇理解、写作、学科知识和实际研讨，因此每课连接「零基础 → C1」综合路线。

## 学习、复习与测评

1. 学完讲解和例子，完成三道题；错题按解析回到规则或语境。旧题记录只说明原客观练习情况，不自动补出新的书写、口头练习或自评。
2. 完成本课独立输出。基础阶段允许中文解释与声音标注；高级阶段逐渐要求 1–4 分钟的说明、数据简报或研讨，并记录具体修订。文本框保存演练或反思记录，不上传/分析录音。
3. 三题正确、输出填写且三项自查完成后，可进入到期复习流程。回忆卡先遮答案，自己回忆再比较；复习计划和自评级别见 `docs/foundations.md`，单次选择题完成不等于长期掌握。
4. 每阶段测评使用独立材料，阅读与听力各三题；输出另行记录。查看听力文本属于辅助条件，应与不看文本的尝试区分。重复同一套题是练习，不能当成独立的标准化复测。
5. 使用本课的「衔接主路线」继续对应等级的综合语言任务。主路线中的基础链接仍能按稳定 ID 返回原课；主路线与专项保持各自练习与测评记录。

阶段客观题覆盖：Pre-A1 的音素与短指令；A1 的元音例外与日常安排；A2 的词尾、语境读音与更新信息；B1 的意群、重点、修复和操作条件；B2 的数字尺度、归属与学术提案；C1 的指标区别、区间信息、来源综合、条件支持与未决事项。它们评价规则解释和内容理解，不测声学发音质量。

## 发音、音频与能力边界

- 基础标音采用宽式、常见 General American，使用 `/i u ɛ/` 等约定；词典使用 `/iː uː e/` 不自动意味着谁读错。`/ɝ/` 与 `/ɚ/` 在本课分别标重读与非重读 r 色彩元音。
- 保留 `/ɔ/` 与 `/ɑ/` 的教学区别，同时承认部分口音合流；wh/w、元音后 r、tomato 等合法变体不作为一律错误。六类书面音节、音节分块和词块都只是工具，不穷尽真实语音。
- 大写表示拟突出部分，`/` 或 `‿` 用于意群或连接标记；这些不是精密声学转写，不能要求每个说话者在同一位置停相同时间。
- TTS 播放完整文本，不能保证产生可控的对比重音、语调、弱读或多人声源。听力题依赖明确词语表达的信息；词重音与对比焦点题使用清楚的书面提示，不伪称音高识别测验。设备声音数不等于覆盖真实口音数。
- 课程不录音、不自动检测音素、重音、礼貌、抢话或流利度。需要真人录音、词典音频、同伴/教师反馈的任务必须诚实记录；尚未实施就注明待验证，不能把 TTS 或自演练写成真人互动。
- 数字、图表和研究报告多为明确标注的虚构练习材料。报告“未给区间方法”不等于断言原研究没有该方法；来源摘要没有提比较组，也不等于断言不存在比较组。课程训练保留证据范围，避免编造研究细节。
- 读完 48 课或填写自查只能证明相关练习记录，不表示官方 C1 认证、研究生入学达标或每种真实学术场景都已掌握。

## 来源与编写方式

材料、案例、问答、提示和测评为本项目编写；以下一手/机构资料用于核对概念与教学方向，没有复制其整套课程、音频或题库。

1. [University of Florida Literacy Institute — Glossary](https://ufli.education.ufl.edu/resources/teaching-resources/glossary/)：音素、字素、合音/拆音、组合与连缀等概念。[IES 基础阅读技能指南](https://ies.ed.gov/ncee/WWC/PracticeGuide/21) 支持从声音与拼写联系走向连贯文本；其 K–3 证据不能直接当作成人自学课程效果证明。
2. Iowa State University 开放教材 *Teaching Pronunciation with Confidence*：[Word Stress](https://iastate.pressbooks.pub/teachingpronunciation/chapter/6-word-stress/)、[Rhythm](https://iastate.pressbooks.pub/teachingpronunciation/chapter/7-rhythm/)、[Prominence](https://iastate.pressbooks.pub/teachingpronunciation/chapter/proninence/)、[Intonation](https://iastate.pressbooks.pub/teachingpronunciation/chapter/chapter-9-intonation-tune/)、[Diagnostic Tasks](https://iastate.pressbooks.pub/teachingpronunciation/chapter/chapter-11-diagnostic-tasks/)：核对词重音、意义分组、焦点、语调与可观察的诊断任务。参考概念不意味着本课程获得该校认证。
3. [Cambridge Dictionary 发音入口](https://dictionary.cambridge.org/us/pronunciation/)：核对词形、US/UK 标音与真人录音；人名、专名和具体学科约定仍需向合适来源核实。
4. [Council of Europe — CEFR descriptors](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-descriptors)：为整条路线的理解、表达与互动目标提供参照。课程阶段为项目编排，不声称 CEFR 为每一音素或拼写模式指定了这里的等级。
