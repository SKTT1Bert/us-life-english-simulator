# Pre-A1 到 A2：基础阶段

核对日期：2026-10-22。能力阶段对照 CEFR 官方描述，课程分级为编辑判断，不是经过验证的等级认证。所有阅读、听力、题目和参考回应为项目原创。每阶段 8 课、32 道课内题、8 道独立测评题及写作和口头任务；详细运行语义见 [学习路线](zero-to-c1.md)。

## Pre-A1 · 零基础起步：字母、声音与第一句话

从字母形状、字母名称和最短句开始。允许先看中文支架、慢速重听，再遮住支架尝试。八个单元需要分次练习；看过一次不等于会用。

| 课节 | 训练重点 |
| --- | --- |
| 01 · 看懂字母，开口打招呼 | 配对 26 个大写、小写字母；区分字母名称和它在单词里的发音；说 hello 和 goodbye |
| 02 · 听清姓名，礼貌要求重复 | 用字母逐个拼出自己的名字；听不清时说 Repeat, please. 或 Slowly, please. |
| 03 · 从零到二十：数量与编号 | 把 0–20 与英文数字对应；区分数量和逐位读出的房间编号 |
| 04 · 我是谁：I am / you are / she is | 用 am、are、is 表达本人或他人身份；在简单身份句中加入 not |
| 05 · 认物品：a / an、this / these | 用 this is 与 these are 指认近处物品；依据发音选择 a 或 an；给常见名词加复数 -s |
| 06 · 表达需要：水、帮助和谢谢 | 用 I need ... 表达基本需求；听懂有无物品的答复并礼貌结束 |
| 07 · 看懂星期与整点 | 识别星期一至星期日和 1–12 整点；用 on + 星期、at + 时刻描述一次活动 |
| 08 · 听指令，完成第一次小任务 | 理解 open、close、write、listen 等短指令；完成两步任务，并在没听懂时请求帮助 |

阶段测评：给一位新同学写简短资料卡：姓名与拼写、一次课的星期和时间、房间号。再写一句礼貌请求。 不读示例，问候、说姓名和身份，告诉对方自己的课何时何地上；然后请求对方重复。实际开口，记录说过的句子或困难。

## A1 · 日常起步：把短句连成可用交流

围绕自我介绍、生活安排和简单事务构建短对话。练习问答、否定和信息核对；先正确表达关键信息，再逐步减少中文支架。

| 课节 | 训练重点 |
| --- | --- |
| 01 · 介绍自己，也问对方 | 用 be 与 live 描述身份和住所；用 Where / What 问题交换基本个人信息 |
| 02 · 一天怎样过：一般现在时 | 描述平时的活动，区分 I 和 she 的动词形式；理解频率词与简单否定句 |
| 03 · 描述住处：there is 与位置 | 描述房间里有无某物；用 next to、between、opposite 给出相对位置 |
| 04 · 买食物：数量、价钱与偏好 | 区分可数和不可数食品的常见表达；核对菜单价格与实际需求 |
| 05 · 问路与坐车：抓住顺序 | 按 turn、go past 等动作理解短路线；用车次、方向和站名核对交通信息 |
| 06 · 平时与此刻：现在进行时 | 用 be + -ing 描述正在发生的动作；区分通常习惯与今天的临时安排 |
| 07 · 能做什么，怎样请别人帮忙 | 区分 can 表能力与 can 用于请求；根据提示信息作合适回应，并说明不能做的事 |
| 08 · 约时间：接受、婉拒与再确认 | 理解邀请的时间、地点及物品要求；接受或拒绝邀请，并提出简单替代安排 |

阶段测评：写 50–70 词给活动组织者：介绍自己、通常的周末安排、这次能否参加、能提供什么帮助，并问一个真实需要确认的问题。信息可虚构。 用约一分钟完成报名对话：自我介绍，询问地点或时间，说明能力和限制；最后重复双方约定。记录实际说出的内容。

参考依据：

- [British Council · A1–A2 grammar](https://learnenglish.britishcouncil.org/free-resources/grammar/a1-a2)

## A2 · 独立处理日常事务，开始解释原因

从短句走向连贯的小段落：叙述过去、比较选择、讲经历、协商计划并概括简单学习材料。开始区分事实、个人意见和信息不足。

| 课节 | 训练重点 |
| --- | --- |
| 01 · 讲清过去发生了什么 | 用过去式按顺序叙述一次经历；用 did/didn’t 提问或否定，并恢复动词原形 |
| 02 · 当时正在做什么：背景与突发事件 | 用 was/were + -ing 描述过去某时正在进行的背景；用 when/while 连接背景活动与短事件 |
| 03 · 比较选择：价格、距离与实际需要 | 用比较级和最高级比较两项以上方案；根据多项限制做选择并承认取舍 |
| 04 · 说经历，也说明发生的时间 | 用 have/has + 过去分词表达截至现在的经历；在给出已结束的具体时间时切回过去式 |
| 05 · 商量计划：意图、安排与变更 | 用 going to 说意图，用进行时表达已安排的近期活动；读懂行程变更并提出可执行的替代方案 |
| 06 · 提建议：必须、应该与可以 | 区分 must、should、can 的要求强度；用原因支持建议，避免将建议当强制规定 |
| 07 · 遇到问题：条件、步骤与求助邮件 | 用 if 表达可发生的条件及后续行动；写包含问题、已尝试方法和具体请求的邮件 |
| 08 · 读短材料，转述重点而不夸大 | 从短文提取主题、两项细节与一个限制；用自己的短句转述信息，区分材料内容和个人看法 |

阶段测评：写 100–130 词给朋友：概括修理角的用途与两条规则，解释它可能适合谁及一项限制，说明为什么不能据此声称它已经减少垃圾；最后提出你自己的参加计划。 用约 90 秒完成预约情境：讲一个相关过去经历，说明当前时间限制，协商新时间，复述需准备的东西；再回答“如果一小时修不好怎么办”。记录真实口述内容。

- [British Council · A1–A2 grammar](https://learnenglish.britishcouncil.org/free-resources/grammar/a1-a2)

## 内容边界与核验

词根词缀用于形成词义假设；语境和词典决定具体用法。词族重音需要逐词核对，合成语音不是音素课程或发音评分。学术案例和命名来源均为虚构教学材料，不能作为真实研究、作者或数据引用。课程中的模型回应可能是论证框架或片段，不应把照抄参考当作独立输出。

每课理解题区分阅读和听力，并提供答案依据。测评使用不同材料，输出量规聚焦任务、意义和表达。程序校验结构、唯一题目、链接和文本长度；人工核对材料与答案的关系、语言规则、证据限定和课程递进。未进行外部教师等级标定或学习者效果研究。
