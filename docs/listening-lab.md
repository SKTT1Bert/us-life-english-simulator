# 逐句精听与跟读

精听页复用综合路线的全部 48 篇原创听力材料，覆盖 Pre-A1、A1、A2、B1、B2 和 C1。每篇分为稳定编号的句子，可逐句播放、调整语速、听写核对，再进行跟读自评。这里没有新增等级认证，也不自动评价发音。

## 学习流程

1. 选择阶段与材料，先听全文，理解话题。
2. 播放当前句，写下听到的英文。原文默认隐藏。
3. 点击“核对听写”，查看漏词、替换词和多写的词。核对忽略大小写、普通标点，并统一英文弯引号；不会把同义改写或另一种句型自动当作同一句听写。
4. 模仿原句的停顿和重音，选择“还没跟读”“看着原文跟读过”或“不看原文也试说过”。这是学习者自评，不是自动发音评分。
5. 保存结果后，可筛选本篇“需要再练”的句子。未作答的句子不会作为错题。

## 语音和隐私

播放使用设备的英文 SpeechSynthesis 声音，界面明确标注设备朗读，不将它描述为真人录音。不自动播放、不请求麦克风，也不录音。若浏览器缺少英文语音，界面给出具体提示，可先查看原文继续练习。

只保存每次练习的课程与句子编号、词语核对数量、是否完全一致、是否使用原文辅助、跟读自评、播放启动次数与作答时间。听写输入的原文和声音不进入学习记录或同步数据。

未保存输入暂存在当前页面，切换句子仍能找回。关闭或刷新页面前需要保存；浏览器可能提示有未保存的内容。保存失败时输入和核对结果仍保留在本页。已保存结果纳入项目的导出、导入和加密同步。

## 记录解释

“需要再练”依据每句最近一次已保存的记录：听写不完全一致、使用了原文辅助、没有启动过播放，或还未自评独立跟读，均可继续练习。即使所有原词都出现，多写了词也不会被判为完全一致。点击核对后会看到原词，随后修改的答案自动记为使用辅助。

“独立”仅描述本次使用方式与自评，不是已掌握的证明。播放计数只证明设备朗读曾触发启动事件，不证明学习者听完或理解。

句子编号采用 `lesson-id-sN`，由确定性分句算法生成；课程原文或分句算法若改变导致编号语义不同，应同步迁移或版本化记录，不可直接把旧结果套到新句子上。

## 验证

`node --test tests/listening-lab.test.js` 检查 48 篇材料覆盖、所有句子稳定编号、缩写与小数分句、逐词比较、额外词处理，以及最新记录的复习筛选。真实设备声音与音质需在相应浏览器单独检查；自动化中的模拟语音事件不代表真人听音验证。
