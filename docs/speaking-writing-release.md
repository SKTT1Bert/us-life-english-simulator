# 真人音频、表达反馈与阶段小测

## 使用路径

- **练习 → 精听与跟读 → 真人录音**：24 段逐条标注来源的录音，Pre-A1–C1 各 4 段，支持慢速播放、听写、逐词对照和跟读。原 48 篇课程材料继续提供设备朗读，原来的句子编号和练习记录不变。
- **练习 → 口语与写作**：原 48 节综合课的写作和口语任务都能进入反馈工坊；另含 24 个真人跟读任务，以及 12 份小测的 24 个表达修改任务。这里的 144 个任务不是 144 节新课程。
- **写作反馈**：Harper 2.13.0 在本机检查语法、拼写和部分表达问题。展示原句片段、中文问题类别、英文说明和可选择的修改。只在学习者选择时应用建议；改文后旧反馈失效。每次保存保留原文、修改文本、来源和反馈快照。
- **口语反馈**：麦克风或文件录音，最长 30 秒 / 8 MB。先回放，再由本机 Whisper tiny.en 转写。可修改转写，并明确区分机器转写、人工修改和手动输入；跟读按文字与原句比较，开放表达可使用语言检查和课程任务自评。完整演讲可以分段练习。
- **复习与修改**：汇集尚有语言建议、自评未确认、或 7 天未练的任务。从历史版本继续时新增一条记录；不覆盖以前的作答。
- **阶段小测**：6 阶段各 A/B 两卷，共 72 道客观题，涵盖听力、阅读和语言运用；每卷附独立写作和口语任务。听力必须触发真实播放才计入听力表现，漏答和未听记录分别标注。提交后提供解析、原文及进入表达修改的入口；同一卷复测受记忆影响。

## 数据与隐私

原主存储键、schema v3、课程题目和历史成绩继续使用。新 `skillWorkshop: {version:1, attempts:[], assessments:[]}` 是附加字段。没有此字段的旧文件读成空集合；不重解释旧记录。新真人听写条目使用 `human-<audioId>-s1`，继续沿用现有 `learningStudio.listeningAttempts` 结构。

新记录通过 `skillAttempt` 和 `skillAssessment` 逐事件同步，原客户端加密、中转服务和配对码不变。并发记录取并集；缺少新字段的旧副本不会删除这些记录。开启同步的设备需要刷新到新版；遇到无法识别的新路径时旧客户端失败并保留本机数据，不应强行回退或清空存储。活跃录音、处理中请求、未保存文字与测评草稿都会阻止云端结果覆盖当前编辑。

保存内容包括文字、建议、自评和时间；语音原文件和 PCM 缓冲只在当前页面内存中，不进入 localStorage、导出或同步。关闭/刷新页面会丢弃未保存内容与录音；页面会提示未保存状态。离开页面或切换后台会停止录音和推理。录音权限由浏览器在点击录音时请求。

两个检查工具都按需从本站下载，不使用付费 API，不向第三方分析服务发送录音或文字。语音资源约 58 MB，写作资源约 20 MB；首次加载需要网络，之后能否免下载取决于浏览器缓存。文本输入、课程和旧记录不依赖工具加载成功。没有宣称完整离线 PWA 能力。

## 能力边界

- 真人库当前是 **一位说话者、24 段短句/短段**，不是完整多口音长篇课程。原始音频及作者许可见 [AUDIO-CREDITS](../AUDIO-CREDITS.md)。今后扩大说话者、语域和篇章长度仍需授权与听审。
- ASR 会漏词、替换或幻听。静音检测可排除近乎无声录音，但不能保证转写正确。文字匹配不能代替音素、重音或语调评分。本版没有编造这些评分，也不是自由对话 AI 教师。
- Harper 是自动语言检查器，不评估事实、论证、观点、任务语义是否完整，也可能误报专有名词。中文分类和结构提示辅助理解，建议由学习者逐项确认；没有自动 CEFR 写作分数。
- 阶段小测属于形成性练习，A/B 卷未进行等值校准。6 道客观题不足以做等级认证；口语、写作任务自评单独展示。仍需教师审题、学习者试测、评分一致性与信效度研究。
- 当前以本地与 CI Chromium、手机尺寸模拟、线上隔离浏览器验证。不能把这些结果描述为已完成真实 iPhone/Android 硬件及麦克风准确率测试。

## 维护与验证

`data/humanAudio.js` 包含逐文件字节数、SHA-256、作者、来源和许可。`vendor/learning-assets.json` 固定运行时、模型修订和文件哈希。模型权重仅用于本机英语转写，与原本地翻译模型无关；第三方许可见 [vendor/README](../vendor/README.md)。

新增语音/测评内容必须使用新编号或新版本；不得改变旧题答案的解释。反馈快照随保存时的版本保留，不在升级后自动重算历史记录。

```text
node --test tests/*.test.js
node tests/skill-runtime-browser.cjs
node tests/skill-workshop-browser.cjs
node tests/sync-browser.cjs
```

真实引擎测试不替换推理；工坊测试使用真实音频、真实语法与语音工具，麦克风生命周期用独立合成音源验证。同步测试默认使用显式加密传输夹具；`SYNC_PRODUCTION=1` 使用已部署页面及真实服务，`SKILL_PRODUCTION=1` 验证线上工坊。所有验收使用隔离浏览器和合成学习记录，不向用户的实际学习历史写入测试成绩。
